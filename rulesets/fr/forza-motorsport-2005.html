Règlement officiel de la communauté

Forza Motorsport [2005]

Sélectionnez un titre pour ouvrir ou fermer la partie correspondante de l’arborescence des règles.
  • Règles générales
    • Tous les runs nécessitent une vidéo de vérification.
    • Les vidéos doivent être hébergées de manière sûre et permanente. Nous recommandons YouTube ou des VOD Twitch permanentes.
    • Si la vidéo devient indisponible, le run pourra être rejeté.
    • Les décisions des modérateurs prises après une réévaluation ne doivent pas faire l’objet de nouveaux messages privés ou de spam.
    • Le son du jeu doit être audible pendant le run.
  • Forza Motorsport
    • Forza Motorsport [2005]
      • Runs complets
        • Tous les paramètres de difficulté sont autorisés.
        • Toutes les améliorations et tous les réglages de tuning sont autorisés.
        • Les pauses et l’ouverture des menus sont incluses dans le temps final.
      • Toutes les courses
        • Le chronométrage commence lorsque le bouton « Démarrer la course » est pressé.
        • Le chronométrage se termine à la dernière image pendant laquelle le joueur contrôle la voiture dans la dernière course.
        • Toute voiture disponible dans le garage du joueur peut être utilisée si le jeu l’autorise.
        • Le temps est mesuré en temps réel (RTA).
      • Runs de série
        • Le chronométrage commence lorsque le bouton « Démarrer la course » est pressé pour la première course de la série sélectionnée.
        • Le chronométrage se termine à la dernière image pendant laquelle le joueur contrôle la voiture dans la dernière course de cette série.
        • Le temps est mesuré en temps réel (RTA).
      • Contre-la-montre
        • Le chronométrage utilise le temps du jeu (IGT).
        • Le temps final correspond à la valeur affichée par le jeu à la fin du contre-la-montre.
      • Runs de carrière
        • Le chronométrage d’une catégorie de déblocage commence lorsque le joueur confirme le nom de son profil.
        • Le chronométrage d’une catégorie de déblocage se termine lorsque le jeu confirme que la catégorie a été débloquée.
        • Le chronométrage d’un run Carrière Any% commence lorsque le joueur confirme le nom de son profil.
        • Le chronométrage d’un run Carrière Any% se termine à la dernière image de la dernière course de carrière requise.
        • Les runs de carrière peuvent être réalisés en plusieurs parties enregistrées.
          • Avant de mettre le jeu en pause, le joueur doit montrer le garage, l’argent disponible et le chronomètre actif.
          • Les mêmes informations doivent être montrées avant de continuer la partie enregistrée suivante.
      • Runs individuels (IL)
        • Le chronométrage utilise le temps du jeu (IGT).
        • Le temps soumis doit correspondre au résultat affiché à la fin de la course.
