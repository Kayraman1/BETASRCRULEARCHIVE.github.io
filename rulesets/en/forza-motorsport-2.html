Official community ruleset

Forza Motorsport 2 [2007]

Select a heading to open or close that part of the rule tree.
  • General Rules
    • All runs require video verification.
    • Videos must be securely and permanently hosted. YouTube or permanent Twitch VODs are recommended.
    • If the video becomes unavailable, the run may be rejected.
    • Moderator decisions made after a re-evaluation must not be targeted with further direct messages or spam.
    • Game sound must be present during the run.
  • Forza Motorsport
    • Forza Motorsport 2 [2007]
      • Full Game Runs
        • Any difficulty settings are allowed.
        • Any upgrades and tunings are allowed.
        • Pausing and opening menus count toward the final time.
        • All Races
          • Timing starts when the Start Race button is pressed and ends on the final frame where the player controls the car in the last race.
          • Garage cars may be used if the game allows them.
          • Timing is measured using real time (RTA).
        • Time Trials
          • Timing uses in-game time (IGT).
          • The final time is the time displayed by the game at the end of the time trial.
        • Career Runs
          • Timing starts when the Start Race button is pressed for the first race and ends at the end of the last race.
          • Timing is measured using real time (RTA).
        • Career Any%
          • Timing is measured using real time (RTA).
          • Timing starts when a fresh save is created.
          • Career Any% runs may be completed in multiple parts. A timer is required when the run is completed in multiple parts.
            • Before pausing the run, the runner must show their garage and money. The same information must be shown before unpausing the timer for the next part.
        • Career Category Runs
          • Timing is measured using real time (RTA).
          • Timing starts when the Start Race button is pressed for the category’s first race and ends at the end of its last race.
          • Example: Proving Grounds — Flyweight Invitational.
          • Endurance categories are an exception. Because they consist of a single race, timing uses in-game time (IGT).
          • The final time is the time displayed by the game at the end of the race.
      • Individual Level Runs (IL)
        • Timing uses in-game time (IGT).
        • The run time is the time displayed by the game at the end of the race.
