Frequently asked questions

About the archive

Select a question to open or close its answer.
  • What is this website?

    This is a community-maintained archive for the Forza speedrunning boards and their rulesets. It provides direct links to the leaderboards and makes the rules easier to read in multiple languages.

  • Where do I submit a run?

    Select your game in the Boards section and open its speedrun.com leaderboard. Runs are submitted and verified through the appropriate game board, not directly through this website.

  • Which ruleset language opens first?

    Rulesets open in English by default. Use the language selector at the top of a ruleset page to switch to another available translation.

  • What happens if a translation differs from the English rules?

    The English ruleset should be treated as the primary version if a translated rule is unclear or outdated. Translation problems can be reported to the Forza Mod Team.

  • Why must run videos remain available?

    Moderators may need to review a run again after its original verification. A permanently accessible video ensures that the submitted run can still be checked.

  • How Should i Name my videos?

    Altough we will not set Strict Rules for Naming your Videos as many runners also use Timestamps/ Different Name for bigger videos On Full game runs this template : [Category] [Variables] [Time] or on ILs this one : [Category] [Class] [Time] may make the verification or later re-verification progress a lot easier both for the moderator and runner

  • How do I report an error?

    Contact a moderator through the Discord Server or SRC and clearly identify the game, category, rule, or translation that needs to be reviewed.

  • Is this an official speedrun.com or Forza site?

    No. This is an independent community project maintained by the moderators responsible for the Forza speedrunning boards.
